# ED-M08 M08.1 — Native material-slot foundation

Status: **shared native model and algorithms implemented and test-validated**.
Geometry/scene production, persistence, reimport continuity and override behavior
remain open. This increment does not change a cooked format or complete slots.

## Implemented

`Oxygen.Data` owns a distinct, opaque, 16-byte `MaterialSlotId`. Its text codec
requires canonical lowercase UUID text without imposing SourceKey's UUIDv7
policy. Nil is an unset value and is rejected as an inventory slot identity.

The inventory model follows content-pipeline section 20: schema version,
geometry identity, native layout revision, declared slots and per-binding
LOD/submesh/default-material identity. Validation checks the exact geometry,
schema, unique IDs, unique surface ownership, complete coverage, exact defaults
and recorded revision against an authoritative native surface inventory.
Equal labels/defaults remain distinct slots. Defaults may differ across bindings;
nil defaults retain the existing native omitted-reference/default-material
semantics.

The canonical writer sorts IDs by all 16 bytes and bindings by numeric LOD and
submesh indices. It emits fixed-schema UTF-8 JSON and hashes those exact bytes
with the existing native SHA-256 implementation. Display order is unchanged.
Labels, the geometry asset key and material payloads are outside the layout hash;
geometry identity is checked separately.
