M08.1 remains open for the remaining canonical data contracts. Rendered flag

## Implemented contract

Scene source/cooked format v5 replaces v4. The 72-byte native `NodeRecord`
stores local values and inherited-source masks separately. Visibility, geometry
casting and geometry receiving support inheritance. Native validation rejects
unknown bits, unsupported inheritance and overlapping local/inherited values.
There is no v4 compatibility reader.

The source schema uses `inherit|shown|hidden` for visibility and `inherit|on|off`
for casting/receiving. Native creation and descriptor production give new roots
explicit Shown/On/On and children Inherit; root Inherit resolves to Shown/On/On.
Hydration preserves the source modes. Existing editor document booleans become
explicit local modes in the native JSON bridge; editor Inherit controls remain
M08.4 work.

Native Inspector validates scenes through the native parse-only loader and
publishes `oxygen.cooked-scenes.v1` metadata: source/asset/path identity, version,
node identity/hierarchy/names and authored flag modes. Its production schema
ships with Inspector tooling. This is content metadata, not a qualification
protocol or an effective renderer observation.

PakGen now requires an explicit, canonical lowercase, non-nil UUIDv7
`source_identity` in every specification. Cooking preserves it without generation
or header repair. Its v5 scene writer, native-format inspection, maintained
specifications, golden packages and tests use the canonical layouts. Content
tests invoke the configured Python interpreter and no longer rewrite source
identities or CRCs after package production.

The managed binary scene writer is retired. Scene-containing managed cook batches
fail before output mutation, including cached imports. Native scene production
is the product path; useful managed source extraction and material/texture
processing remain available.

## Remaining gates

M08.1 still requires material-slot identity/inventory/provenance/overrides,
camera aspect policy, atmospheric roles, float32 emission and removal of the
ineffective capture toggle, including their producers, hydration, migration and
recooking. CPU flags and metadata do not prove M08.2 rendered eligibility,
independent light/caster/receiver behavior or renderer invalidation. The native
example checks are supplemental evidence; M08.3–M08.8 remain open.
