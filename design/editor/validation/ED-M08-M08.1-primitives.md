# ED-M08 M08.1 — Canonical primitives and maintained examples

Date: 2026-09-16. Status: **implemented and focused-test-validated; M08.1 open**.

## Implementation

- IcoSphere is the sole subdivided-icosahedron identity in native APIs, catalog,
  schemas, Lua, managed clients, fixtures and documentation. Catalog v2 classifies
  nine standard shapes, advanced SubdividedCube and internal ArrowGizmo. Managed
  authoring projections expose ten shapes and reject obsolete catalog versions.
- Quad uses XZ with front -Y. Torus defaults use major radius .4 and minor radius
  .1. Procedural parameter guards cover finite float32 dimensions and safe counts;
  generated tangent frames follow increasing texture coordinates. Direct factory,
  descriptor and Lua routes share defaults. Unknown Lua geometry retains the
  previous geometry and reports failure. Unsupported cooked recipes produce a
  loader error instead of an empty-mesh assertion.
- Maintained physics content uses IcoSphere. LightBench cards use Quad with
  authored rotations/scales migrated to preserve placement. All 66 lights across
  the 14 maintained scene sources now explicitly specify shadow bias: 57 omitted
  values became .03; existing explicit values remain unchanged. Example-created
  suns also default to .03. RenderScene keeps its existing **Use Scene** startup
  policy; a persisted Custom value is intentionally not the active scene value.
- Validation exposed a forward-shadow ABI mismatch. Forward and deferred now
  consume the same native shadow-frame layout and directional sampling helper.
  Obsolete metadata readers were removed. The geometric-normal helper is unchanged.
- The Windows asynchronous writer permits cooperative readers while preserving
  write exclusion. Writer tests use isolated process/fixture directories so
  parallel runs cannot remove another test's output. This fixes a reproduced
  sharing defect; the earlier texture append failure's OS cause was not recorded.
- BufferPipeline constructs its default configuration out of line, preserving
  its aggregate configuration API and runtime defaults while allowing Clang
  to compile the importer for static analysis.
- Orbit synchronization preserves authored poses and roll on idle updates,
  with world-space target/radius semantics. Parented pose conversion uses engine
  transform conventions. Both physics-domain cameras explicitly aim at the scene
  origin using Oxygen's camera-local -Z/+Y basis in its right-handed Z-up world.
  Scene traversal updates dirty `IgnoreParentTransform` nodes and descendants;
  changing that flag invalidates their cached world transforms.
