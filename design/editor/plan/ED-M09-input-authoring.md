# ED-M09 - Input Authoring

Status: `planned; design and plan not started`

## Purpose

Users create and edit input actions and mapping contexts in the editor
(REQ-045). The milestone owner designs the user interface and writes this
plan's slices and acceptance.

## Starting point

- The engine already imports, cooks and runs input actions and mapping
  contexts.
- ED-M08 cooks hand-written input files found under authoring mounts and
  lets scripts and the scene's Play section reference their assets
  ([script authoring](../lld/script-authoring.md)).

## Note on the ID

ED-M09 previously named the viewport authoring tools, which ED-M08.4–M08.6
delivered on 2026-10-08.
